# Security Policy

## Supported Versions

Only the latest major version receives security fixes.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Use [GitHub's private vulnerability reporting](https://github.com/petroslabs/fr-validator/security/advisories/new)
on this repository, or email **petroslabs@proton.me**.

Include a description of the issue, steps to reproduce, and the impact you'd
expect (e.g. "a crafted RIB bypasses the checksum check"). We'll acknowledge
within a few days.
